# Dropverket sound library

- Drum one-shots: TR-8 recordings from MckAudio/MckSamplePacks (CC0 1.0) and the Roland TR-808 sample set by Michael Fischer via tidalcycles/sounds-tr808-fischer (CC0 1.0).
- Loops, synth sounds and effects: rendered for Dropverket by `scripts/dropverket/build_library.py`, released under CC0 1.0.
